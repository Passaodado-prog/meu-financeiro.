Segurança dos dados

Backup dos dados

Exporte uma cópia completa ou restaure seus dados a partir de um arquivo salvo.

Exportar backup completo

Baixe um arquivo JSON com cartões, lançamentos, despesas fixas, receitas recorrentes e os comprovantes JPEG/PDF anexados e investimentos cadastrados. Guarde esse arquivo em local seguro. A senha e as respostas de recuperacao dos investimentos ficam neste navegador e nao sao incluidas no backup.

Restaurar backup

Importe um backup JSON para restaurar os dados e os arquivos dos comprovantes. A restauração substitui os dados atuais; exporte um backup antes se quiser preservar o estado atual.

Armazenamento local

Os dados ficam neste navegador e dispositivo. Os comprovantes usam armazenamento local separado; exporte backups periódicos para preservar também os arquivos.

Armazenamento local ativo
Sistema iniciado sem dados cadastrados. Cadastre seus cartoes, receitas, despesas e investimentos para comecar.
